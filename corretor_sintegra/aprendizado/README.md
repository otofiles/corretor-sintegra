# Aprendizado SINTEGRA

Pasta de pesquisa e documentação sobre o SINTEGRA (Convênio ICMS 57/95),
para embasar os corretores do projeto.

## Índice

- [01 - Estrutura dos registros](01_estrutura_registros.md)
  Layout completo (posições 1-based) de todos os tipos de registro.
- [02 - Validação SINTEGRA](02_validacao.md)
  Como o Validador SINTEGRA (valArqSint/SEFAZ) valida o arquivo: montagem,
  classificação, campos, regras de aceite/rejeição/advertência.
- [03 - Erros comuns e corretores](03_erros_comuns.md)
  Tabela dos erros mais frequentes encontrados na prática e o corretor
  correspondente deste projeto (existente, novo ou pendente).
- [04 - Catálogo de CFOP](04_cfop.md)
  Critérios de validação estrutural de CFOP usados nos corretores.

## Fonte oficial

- Convênio ICMS 57/95 e alterações — Manual de Orientação (Confaz/SEFAZ).
- Programa Validador SINTEGRA (distribuído pelas SEFAZ).
- Leiaute do anexo VII do RICMS (MG, ES, etc.).
